# Theme Name: ASTRO Deep Space Spatial Laboratory

# Vibe & Description:
NASA Deep Space Astrophysics Laboratory & Scientific Instrument. Near-black cosmos canvas (#030712), precision navy/indigo glass surfaces (#0F172A, #1E1B4B), crisp telemetry typography with tabular numerical readouts, restrained cyan (#06B6D4) and violet (#8B5CF6) accents, delicate 1px precision grid borders, and true scientific evidence visualization.

# Color
- Primary: #6366F1 (Indigo Scientific Accent)
- On Primary: #FFFFFF
- Accent: #06B6D4 (Telemetry Cyan)
- On Accent: #FFFFFF
- Background: #030712 (Near-Black Cosmos)
- Foreground: #F8FAFC (Off-White Telemetry Text)
- Muted: #1E293B (Deep Slate Surface)
- Border: #1E293B (1px Precision Grid Border)
- Secondary: #312E81 (Deep Indigo Layer)

# Font
- Heading: Inter / Space Grotesk (font-family: 'Inter', sans-serif, weight: 600)
- Body: Inter & JetBrains Mono for telemetry numerals (font-family: 'Inter', 'JetBrains Mono', monospace)

# Visual Language
- Core visual signature: Precision scientific telemetry HUD with real coordinate grids, mathematical vectors, and evidence status badges (OBSERVED 🟢, CALCULATED 🔵, SIMULATED 🟣, HYPOTHETICAL 🟠, UNCERTAIN 🔴).
- Material & depth: Subtle semi-transparent dark glass surfaces (backdrop-blur-md bg-slate-900/80), fine 1px slate borders, layered depth with distinct 3D spatial viewport elevation.
- Containers & buttons: Crisp 6px-8px radius, fine border highlights on active state, telemetry status pills, minimal restrained glows.
- Layout rhythm: Full-bleed interactive 3D spatial viewport with collapsible side inspectors, floating camera/scale toolbars, and responsive scientific telemetry panels.

# Animation
- Entrance: Subtle fade-in + scale (200ms ease-out) for HUD cards and inspector panels.
- 3D Camera transitions: Smooth spherical lerping (slerp) between target focus points and orbital viewpoints.
- Telemetry updates: Instantaneous numerical readout transitions with tabular numbers to prevent layout jitter.

# Forbidden
- No cartoon planets, neon arcade glows, or oversized sci-fi video game HUDs.
- Never imply false physical scale without prominent "DISTANCES NOT TO SCALE" warnings.
- No decorative emojis in scientific telemetry and headers.
